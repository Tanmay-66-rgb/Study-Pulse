# StudyPulse 🚀
Ultimate Exam Prep & Readiness Hub

StudyPulse is an all-in-one productivity and study-tracking web application designed to help students prepare effectively for exams. It combines interactive timer workflows, dynamic syllabus tracking, and performance analytics to transform daily study habits into actionable insights.

## Try Study Pulse: https://study-pulse-app.netlify.app/

## ✨ Features
### ⏱️ Interactive Pomodoro & Custom Timer

Standard Pomodoro intervals (25/5 and 50/10) with custom duration settings.

Session tagging by Subject and Topic.

Automated session history logging.

## 📚 Syllabus & Topic Management

Subject and topic breakdowns.

Real-time progress bars tracking topic completion.

Linked study hours calculated per module.

## 📊 Analytics & Exam Readiness Dashboard

Visual metrics comparing logged hours against subject mastery.

Mock test score tracking and score vs. effort analytics.

Automated exam confidence estimation algorithm.

## 💾 Data Persistence

Built-in local storage / database synchronization to keep track of daily study history.

## 🛠️ Tech Stack
Frontend: React, TypeScript, Vite

Styling: Tailwind CSS, Shadcn UI

Icons: Lucide React

State & Data Management: React Hooks, Supabase / LocalStorage



## 📌 Usage Guide
Add Your Subjects & Topics: Go to the Syllabus tab and create your subject list with specific revision topics.

Start a Session: Choose your active subject, configure your timer interval, and press Start.

Log Mock Test Scores: Record practice test scores in the Analytics section to track growth over time.

Review Your Dashboard: Monitor total study hours and overall readiness score to optimize your timetable.
